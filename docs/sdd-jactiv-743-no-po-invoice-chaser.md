## 1. API Workflow Overview

Weekday automated run (10:00 EET/EEST, Europe/Bucharest) that queries Coupa for draft/new invoices dated in the past seven days, identifies those with no properly linked PO object, counts qualifying records, and sends one Slack Block Kit DM to the AP SME. No message is sent when count is zero (BR-07).

## 6. Error Handling

No retry, fallback or alternative notification is specified (BR-08, BR-09). A single edge `Try/Catch` wraps the entire sequence; any unhandled exception marks the run failed in Orchestrator with the stack trace logged. No Slack notification is sent on failure (BR-09).

| Failure | Detection | Response |
|---|---|---|
| Coupa 5xx / timeout (S1) | HTTP error at step 4 | Edge catch; run failed; no Slack |
| Coupa 401/403 (S2) | HTTP error at step 4 | Edge catch; run failed; credential error logged |
| Slack 5xx / timeout (S3) | HTTP error at step 7b | Edge catch; run failed; no retry |
| Slack auth failure (S4) | HTTP 401/403 at step 7b | Edge catch; run failed |
| Slack `ok ≠ true` | `Javascript_ValidateSlack` throws | Edge catch; run failed |
| Network timeout (S5) | Timeout on any HTTP call | Edge catch; run failed |
| Unhandled exception (S6) | Any runtime error | Edge catch; stack trace logged; run failed |

## 8. Testing Strategy

### Happy Path

| # | Condition | Expected |
|---|---|---|
| H1 | Coupa returns ≥1 invoice with no linked PO, not a credit note | Slack DM posted; `qualifying_count` correct; `slack_sent=true` |
| H2 | Block Kit DM received by `WLX9BD8FN` | Header, 3-line section, Coupa button, footer all render correctly |
| H3 | Coupa button URL contains correct window dates and `status_eq=draft` | Filtered view opens in Coupa |
| H4 | All invoices have linked POs — count = 0 | No Slack DM; `qualifying_count=0`; `slack_sent=false` |

### Business Exceptions

| # | Condition | Expected |
|---|---|---|
| B1 | Credit-note invoice in Coupa response | Excluded; logged; not counted (BR-03) |
| B2 | Invoice with PO number in description only, no linked PO object | Counted as qualifying (BR-02) |
| B3 | Invoice_count = 0 after all filters | Silent exit; no DM (BR-07) |

### System Errors

| # | Condition | Expected |
|---|---|---|
| SE1 | Coupa API HTTP 5xx | Run failed; no DM; job log entry (BR-08, BR-09) |
| SE2 | Coupa API HTTP 401/403 | Run failed; credential error logged |
| SE3 | Slack API HTTP 5xx | Run failed; no retry; job log entry |
| SE4 | Slack `ok=false` in response | `Javascript_ValidateSlack` throws; run failed |
| SE5 | Network timeout | Run failed; Orchestrator alert |
